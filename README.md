# 듣고두고 작품 서재

듣고두고 앱에서 내려받는 영어 완독본의 본문과 문장별 재생 정보입니다.
이 저장소에는 앱 소스 코드, 계정 정보, 번역 캐시, 개인 학습 기록, 음성 파일이 들어 있지 않습니다.

## 자료

- 본문: Project Gutenberg의 책 번호와 GITenberg 보존본 커밋을 각 작품에 기록합니다.
- 낭독: LibriVox의 공개 녹음입니다. 음성은 원 제공자의 Internet Archive 주소에서 재생합니다.
- 문장 구분 및 시간: Storyteller 0.2.4가 만든 결과이며, 전체 본문과 시간 순서를 검증합니다.
- 각 작품의 `sourceNotice`에 원본 이용 안내와 Project Gutenberg 라이선스 전문을 보존합니다.
- 한국어 제목과 작가명은 검색용입니다. 본문과 낭독은 영어입니다.

`catalog.json`은 작품 목록이고, `packages/`는 SHA-256으로 검증하는 불변 작품 파일입니다.
목록에 작품이 추가되면 앱의 **서재 → 작품 더 찾기 → 목록 새로고침**에서 받을 수 있습니다.
음성을 오프라인으로 들으려면 앱의 **다운로드**에서 따로 저장하세요.
